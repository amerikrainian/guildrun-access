# Controls

Every key the mod binds, by group. Keys are keyboard only and not rebindable. F1 shows the subset that does something where you are; that is usually what you want.

## Global

| Key | Function |
| --- | --- |
| F1 | Keys here: the keys that do something on this screen, each runnable with Enter |
| Ctrl+Shift+M | Mod menu |
| Ctrl+Shift+A | Toggle keyboard navigation |

## Navigation

| Key | Function |
| --- | --- |
| Arrows | Move focus; Left/Right adjust a slider |
| Tab / Shift+Tab | Next / previous control group |
| Enter, Numpad Enter | Activate |
| Backspace | Secondary action (on a hero: open it in the compendium) |
| Escape | Back, cancel, close; on a run screen with nothing else to do, the pause menu |
| Home / End | First / last item of the list |
| Alt+Up / Alt+Down | Previous / next section |
| Letters | Type-ahead search in the focused group |

## Buffers

| Key | Function |
| --- | --- |
| Ctrl+Right / Ctrl+Left | Next / previous buffer |
| Ctrl+Up / Ctrl+Down | Next / previous line |

## Run Jumps

These land on a control group from anywhere on the run screen, as Tab would.

| Key | Function |
| --- | --- |
| Alt+B | The board; over a panel, its own group: the shop's offers, the crossroads' paths, an event's choices |
| Alt+T | The party |
| Alt+I | The items and relics |
| Alt+F | Press Fight while placing |

## The Board

The board is a pointy-top hex grid: no cell lies straight up or down. The six letters sit on the keyboard the way the six neighbours sit around a cell.

| Key | Function |
| --- | --- |
| Q / E | Cell up left / up right |
| A / D | Cell left / right |
| Z / C | Cell down left / down right |
| Shift+Q, E, A, D, Z, C | Move the focused hero to that neighbouring cell (from its party slot too, while placing) |
| Up / Down | Jump to a unit toward the enemies / toward your heroes |
| Left / Right | Move along the same side |

## Unit Glances

These speak one fact group of the unit the focused control concerns: a cell, a party slot, a hero card, an event choice that names a hero.

| Key | Function |
| --- | --- |
| 1 | Health, shield, and mana |
| 2 | Attack, magic, and defense |
| 3 | Attack speed, crit, range, and move speed |
| 4 | Regeneration, omnivamp, and resistances (the nonzero ones) |
| 5 | Statuses |
| 6 | Current target |
| Shift+2, 3, 4 | The same, with each stat's breakdown |
| Alt+digit | The item in that slot of the focused hero |
| Alt+Shift+digit | That item's tooltip |
| Alt+R | On the first hero picker: the focused offer's bundled relic |

The number keys on the numpad work too.
