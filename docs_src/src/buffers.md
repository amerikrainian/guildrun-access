# Buffers

Buffers are review lists for extra information. Moving focus chooses what is available; the buffer keys let you read it without moving focus away. The focus line stays short ("Reyna, party slot 2"); everything longer the control carries, tooltips, stat blocks, ability text, lands in a buffer, one line per tooltip.

## Keys

- Ctrl+Right: next buffer. Ctrl+Left: previous buffer.
- Ctrl+Up: next line. Ctrl+Down: previous line.

Switching buffers speaks the buffer's name and its current line. Moving focus puts you back on the control buffer.
