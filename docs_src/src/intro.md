# Introduction

Guildrun Access is a screen reader and keyboard accessibility mod for Guildrun, an auto-battler about drafting heroes, kitting them out, and placing them on a hex board before they fight on their own. The mod adds spoken output, keyboard navigation over every screen, review buffers for everything a control carries, glance keys, and audio cues for the fights.

The game is in active development and updates often. Expect the mod to lag behind a patch now and then.

## Features

- Speech output through Prism, with support for common screen readers and speech backends.
- Keyboard navigation for the menus, settings, the compendium, the hero pickers, the board, the party and items, shops, crossroads, events, results, and the end of a run.
- Review buffers for the focused control, the hero it concerns, its items, quests, the run's relics, both sides of the board, and the battle log.
- Glance keys that answer questions ("how is this unit doing?", "what does slot 3 hold?") without moving focus.
- Audio cues for what a fight shows but never sounds: crits, casts, deaths, statuses arriving and wearing off.
- A context-sensitive key list (F1) that shows only the keys that do something where you are.
- The mod speaks whatever language the game is set to.
